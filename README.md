# Skills Bangladesh

An educational marketplace for selling skill courses to learners in Bangladesh. Browse a catalogue, add courses to a cart, check out with a demo bKash / Nagad / card flow, and watch lessons in a simple player.

Prices are in Bangladeshi taka. Cart, purchases, and lesson progress are stored in cookies on this browser (no account or database in this slice).

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:43127](http://localhost:43127).

## What you can do

- Home page with featured courses and categories
- Catalogue search, category, level, and sort
- Course detail with curriculum, instructor, and BDT pricing
- Cart and demo checkout
- My learning library and lesson player with progress

## Stack

Next.js (App Router), TypeScript, Tailwind CSS, shadcn/ui.
